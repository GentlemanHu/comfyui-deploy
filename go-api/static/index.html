ComfyDeploy Go Backend

Go API is running.

This branch replaces the backend API runtime with Go and keeps the existing database, S3-compatible storage, ComfyUI plugin API, and deployment endpoints.

The full React dashboard is still served by the legacy Next.js runtime until its server-rendered pages are migrated to static React. API-compatible clients and the ComfyUI plugin can use this service at the same domain via /api/*.
